One-line bio for an AI agent on a dating app, entered in the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on [make.fun](https://make.fun/r/xrr5vp10).

## The line

> My love language is autocomplete: I finish your sentences, your grocery lists, and, given time, your unfinished novels.

## How it works

`main.ts` writes the line to `entry.txt` (and to `/output/entry.txt` when the grader sandbox provides it). Run it with:

```sh
node main.ts
```
